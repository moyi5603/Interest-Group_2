# 活动详情页整体抛光（v2）

日期：2026-08-06  
范围：C 端移动 `ActivityDetail`（`site/assets/6e9cd9ec-….js`）  
前置：`docs/superpowers/specs/2026-08-05-activity-detail-app-ui-design.md`（App 化结构已落地）  
状态：已定稿，待实现

## 目标

在现有 App 化结构上做一轮完整打磨：视觉、信息架构微调、交互（含滚动顶栏）。业务规则不变。

## 决策

| 项 | 选择 |
|----|------|
| 策略 | 方案 1：现结构抛光，不重拆 IA |
| 范围 | A 视觉 + B 信息微调 + C 交互 |
| 业务 | 报名/加入门槛/系列场次/精彩瞬间条件不变 |

## 1. 视觉

| 区块 | 改动 |
|------|------|
| Hero | 高度约 280；顶/底渐变更清楚；返回钮阴影略加重 |
| 标题区 | 标题约 22 / 800；状态徽标轻量；小组行作次级入口 |
| 关键卡 | `MetaRow` 左图标列宽统一；行距约 12；分割线后报名进度单独一块 |
| 场次 | tile 略放大、gap 约 12；横滑左右留 padding |
| 简介 | `.richtext img`：全宽、圆角 12、上下间距；多图纵向叠（兼容 AI 创建插入的简介图） |
| 评论 | 列表留白略增；空态更轻 |
| 底栏 | 毛玻璃 + 轻顶阴影；点赞与 CTA 垂直居中 |

## 2. 信息架构微调

- 关键卡：**上块** = 时间、地点、发起人、（系列）报名方式、截止；**下块**（有则显示）= 报名进度 + `AvatarStack`
- 场次卡头：只留「场次」+「已报 X 场」；截止不重复放在场次卡头
- 无简介：隐藏整块「活动简介」
- 标签 pills：仍在简介下，间距略拉开
- 已结束折叠：逻辑不变（折叠仍露标题 + 瞬间/评论）

不改：门槛文案、底栏 CTA 语义、选场 Sheet 流程。

## 3. 交互

| 项 | 行为 |
|----|------|
| 滚动顶栏 | 滑过 Hero（阈值约 200px）后淡入：左返回 + 中间缩略标题；未越过时仍用 Hero 上 `FloatBtn` |
| 场次 tile | 可点区域 ≥ 44；横滑保留 `noscroll` |
| 评论 | 「写评论 / 回复」→ Sheet；发送后关闭 |
| 选场 Sheet | 文案「场」；tile 间距与详情横滑一致略加大 |
| 底栏 | 双 CTA 窄屏不溢出；保留 `safe-area` |
