# PC 管理后台 · 分类管理

日期：2026-08-05  
范围：PC `AdminApp` 新增「分类管理」；数据层 `store.cats`；C/PC 读分类时兼容空 `cat`

## 背景

分类现为写死 `window.CATS`（8 项）。需在 PC 后台支持完整 CRUD + 排序，并与小组/活动 `cat` 联动。

## 决策摘要

| 项 | 选择 |
|----|------|
| 能力 | 完整 CRUD + 排序 |
| 字段 | 名称、图标、颜色、排序 |
| 删除 | 允许；关联项 `cat` 置空，展示「未分类」 |
| 架构 | `store.cats` 为可变源；`getCat(key)` 安全读取 |

## 信息架构

1. 侧栏「兴趣小组」下新增 `categories`「分类管理」，位于「小组管理」下方。
2. 列表页：表格 +「新建分类」；行内编辑 / 上移下移 / 删除。
3. 新建/编辑：Modal 表单（不另开详情页）。

## 列表

| 列 | 说明 |
|----|------|
| 排序 | `order` 数字，默认按升序 |
| 分类 | 图标（着色）+ 名称 |
| 颜色 | 色块预览 |
| 小组 | 引用该 `key` 的小组数 |
| 活动 | 引用该 `key` 的活动数 |
| 操作 | 编辑、上移、下移、删除 |

## 表单字段

| 字段 | 规则 |
|------|------|
| 名称 `label` | 必填，≤ 12 字 |
| 图标 `icon` | 下拉，取现有 `Icon` 名集合（如 `zap` / `bookmark` / `heart`…） |
| 颜色 `color` | 预设 CSS 变量：`--c-sport`、`--c-reading`、`--c-photo`、`--c-outdoor`、`--c-food`、`--c-game`、`--c-music`、`--c-other` 等 |
| 排序 `order` | 整数；新建默认 `max(order)+10` |

- `key`：新建时自动生成（`c` + 时间戳或自增），**创建后不可改**。
- 初始数据：由现有 `CATS` 灌入，`order` 按当前对象顺序 10、20、30…

## 删除与未分类

1. 删除确认文案：若有关联，提示「将有 N 个小组、M 个活动变为未分类」。
2. 确认后：从 `store.cats` 移除；所有 `group.cat` / `act.cat` 等于该 key 的置为 `''`。
3. 展示：`getCat('')` / 未知 key → `{ label: '未分类', icon: 'dots', color: 'var(--ink-3)' }`；**不**自动改挂「其他」。
4. 小组/活动表单的分类下拉：只列当前 `store.cats`；已是空 cat 的项显示「未分类」。
