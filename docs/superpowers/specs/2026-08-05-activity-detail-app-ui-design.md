# 活动详情页 App 化改版

日期：2026-08-05  
范围：C 端移动 `ActivityDetail`（`site/assets/6e9cd9ec-….js`）  
状态：待实现

## 目标

让活动详情在样式、布局、交互上更接近原生活动 App：沉浸浏览、分区清晰、主操作不被评论输入抢占。业务规则不变。

## 决策摘要

| 项 | 选择 |
|----|------|
| 改版深度 | 完整改版（结构 + 底栏 + 场次） |
| 底栏 | 仅点赞 + 主 CTA；评论不进底栏 |
| 评论输入 | 评论区「写评论」→ 底部 Sheet |
| 视觉 | 沉浸 Hero + 分区内容，沿用现有 token |
| 文案 | 系列「期」→「场」（详情页可见文案） |

## 1. 信息架构（上→下）

1. **沉浸封面** ≈ 240–280px  
   - 全宽封面；左上 `FloatBtn` 返回  
   - 底缘叠 `CatBadge` + `TypeTag`  
   - 滚动渐变顶栏：可选；MVP 可不做，优先结构与底栏

2. **标题区**  
   - 大标题（系列展示系列名，否则活动标题）  
   - 所属小组行（可进小组详情）  
   - 可选状态：已结束 / 已报名（轻量徽标，不挡主信息）

3. **关键信息卡**（单卡）  
   - 时间、地点、发起人  
   - 系列：报名方式（整场 / 按场次）  
   - 截止倒计时（有则显示）  
   - 单次：报名进度 + `AvatarStack`

4. **场次区**（周期 `sessions` 或系列）  
   - 标题「场次」+「已报 X 场」（适用时）  
   - 横向 `SessionSlotTile`；触控与间距略放大  
   - 文案统一「场」，不用「期」

5. **活动简介**（富文本）+ 标签 pills

6. **精彩瞬间**（有数据且现有显示条件满足时；逻辑不变）

7. **评论**  
   - `SectionHeader`「评论 N」  
   - 评论列表（点赞 / 回复保留）  
   - 「写评论」按钮 → 打开评论 Sheet

8. **固定底栏**（见 §2）

已结束折叠详情：保留「查看/收起活动详情」行为，折叠时仍露出标题区与精彩瞬间/评论（与现逻辑一致方向）。

## 2. 底栏与评论

### 底栏

- `sticky` 底栏：毛玻璃/半透明底 + 顶部分割线（沿用现风格可微调）
- 布局：`点赞` | 主 CTA 区  
- 单 CTA：报名 / 取消报名 / 调整场次 / 报名并加入小组 / 审核中禁用等（逻辑同现 `renderEnrollBtn`）  
- 双动作：可报名且可发精彩瞬间时，并排「精彩瞬间」+ 报名类按钮  
- 非成员提示条：仍在 CTA 上方，文案与门槛逻辑不变  
- **禁止**在底栏常驻评论输入框

### 评论 Sheet

- 从评论区「写评论」或列表「回复」打开  
- 回复态：展示「回复 @某人」+ 取消  
- 输入 + 发送；成功后关闭 Sheet、toast、列表追加本地评论  
- 不改变评论数据模型（原型本地 state）

### 选场 Sheet

- 保留勾选 / 确认流与门槛  
- 标题与提示「期」→「场」  
- tile 触控与间距略放大，便于拇指操作

## 3. 视觉规范（对齐 EXP mobile）

- Token：`--brand`、`--surface`、`--bg`、`--ink*`、`--shadow-sm`、`--r-lg`  
- 禁止 PC 表格风、新引入 Tailwind  
- 封面更高、标题约 20–22 / 800；正文 14–14.5；辅助 `--ink-3`  
- 区块间距约 16–20；卡片内边距约 14  
- 场次横滑：`noscroll` + 更大 gap / tile

## 4. 业务不变（硬约束）

- 报名前置加入小组（自由加入一键 / 审核加入门槛）  
- 系列 `seriesSignupMode`: `all` | `independent`  
- 周期 / 系列按场调整报名 Sheet  
- `pickEnroll` / `pickEnrollIntent` 深链打开选场  
- 已结束折叠、精彩瞬间入口条件  

仅 UI/交互重组，不改 store actions 语义。

## 5. 实现范围

## 6. 验收

- [ ] 单次 / 周期 / 系列（整场、按场）详情可完整浏览与报名  
- [ ] 底栏无常驻评论框；写评论 / 回复走 Sheet  
- [ ] 主 CTA 与双动作布局在窄屏不溢出  
- [ ] 系列文案为「场」  
- [ ] 非成员 / 审核中提示仍正确  
- [ ] 已结束折叠与精彩瞬间入口正常
