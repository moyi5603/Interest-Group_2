# 管理者端移动 App 化 UI

日期：2026-08-05  
前置：`2026-08-05-mobile-role-admin-design.md`（身份切换 + 四模块）  
范围：`AdminApp variant="mobile"` 四页样式与交互；PC 默认布局不变

## 决策

| 项 | 选择 |
|----|------|
| 范围 | 工作台 / 小组 / 活动 / 分类 全做 |
| 实现 | 现有 Section 加 `mobileAdmin` 分支（不另起一套 Mobile*） |
| 新建编辑 | 全屏页 |
| 删除等轻操作 | 底部 ConfirmSheet |
| 分页 | 手机关闭；列表全量展示（原型数据量可接受） |

## 壳层

- 顶栏：身份切换 + 四 Tab（工作台 / 小组 / 活动 / 分类）；无底栏
- Tab 即页面标题；去掉各页重复 PC 大标题与长副标题
- 主操作：顶栏右侧图标钮（+ / AI）或内容区主按钮
- 详情 / 全屏表单：左侧返回，盖住 Tab 内容（`setView` 推层，同现有 detail/create）

## 四页

### 工作台

- 2×2 指标卡，间距收紧
- 待审核：纵向列表行（申请人 + 小组 + 通过/拒绝）
- 趋势图：矮高度；可保留
- 近期活动：卡片行（封面 + 标题 + 状态），点进 `actDetail`
- 无宽表格、无 PC 分页

### 小组

- 全宽搜索
- 单列卡片：矮封面 + 名 + 成员/活动数 + 加入方式
- 「···」或卡片内按钮：编辑 / 删除；删除走 ConfirmSheet
- 「+」→ 全屏 GroupForm

### 活动

- 活动名搜索为主；小组搜索可次行或省略以省空间
- 类型 Segmented（全部 / 单次 / 周期性 / 系列）
- 列表行卡片：封面约 48、标题、时间、报名进度、状态 pill；点进 `actDetail`
- 「+」→ ActForm 全屏；「AI」→ AIComposer 全屏
- 无 table、无分页控件

### 分类

- 列表行：图标色块 + 名称 + 小组/活动数
- 行内上移 / 下移即时生效；编辑全屏；删除 ConfirmSheet
- 无表格、无「每页 N 条」

## 表单与交互

- 小组 / 分类 / 活动编辑：全屏（返回 + 标题 + 保存）；字段复用现有表单
- `GroupForm` / 分类 Modal：`mobileAdmin` 时改为 asPage 或等价全屏层
- 触控：主操作高度 ≥ 44px；整行可点
- 视觉：员工端同一套 CSS 变量（`--brand` / `--surface` / 圆角阴影）

## 不做

- 不改 PC `AdminApp` 默认样式与表格
- 不做报名 / 评论 / 精彩瞬间管理（手机）
- 不做左右滑删除手势（v1）
- 不新增独立路由；员工端仅保留已有身份切换

## 验收

1. 切到管理者：顶 Tab 切换四页，无底栏、无 PC 表格横溢
2. 小组/活动/分类：卡片或列表行可完成 CRUD
3. 删除有确认条；新建编辑为全屏
4. 切回员工：首页正常；PC 管理端外观与操作不变
