# 移动端身份切换 · 管理者核心管理

日期：2026-08-05  
范围：兴趣小组手机首页身份切换；管理者侧核心四模块（对齐 PC 能力子集）

## 决策

| 项 | 选择 |
|----|------|
| 呈现 | 手机内移动布局管理壳（方案 C） |
| 模块 | 工作台、小组管理、活动管理、分类管理（B） |
| 默认 | 员工 |
| 记忆 | `localStorage` key `exp-app-role`：`employee` / `manager` |

## 员工

- 现有首页（我的活动/小组、AI、活动 Feed…）
- 顶栏左侧增加 `员工 | 管理者` 切换

## 管理者

- 整页切换为管理壳；顶栏身份切换 + 顶栏四 Tab：工作台 / 小组 / 活动 / 分类（无底栏）
- 数据与操作对齐 PC：`groups` / `acts` / `cats` CRUD（内存 store，同 AdminApp）
- 不做：报名、评论&互动、精彩瞬间管理

## 不做

- 不自动跳 Showcase PC 大屏
- 不在手机里硬嵌完整 PC 侧栏布局
